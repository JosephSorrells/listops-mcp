# Accessibility

ListOps review cards are designed to work in ordinary email clients and assistive technologies.

## Design choices

- Plain text.
- Action at the top.
- One-word moderator replies: APPROVE, HOLD, FIX, ESCALATE.
- No required long tokens in the default flow.
- No color-only risk indicators.
- Short lines.
- Clear confirmation language.
- Fail-closed behavior if a command is ambiguous.

## Supported moderator environments

The concept is intended to support moderators using:

- Microsoft Outlook.
- Gmail / Google Workspace.
- Thunderbird / Mozilla.
- HCL Notes / Domino.
- Apple Mail.
- Mobile email clients.
- Screen readers.
- Screen magnification.
- Speech-to-text.

## Accessibility goal

A moderator should not need to learn LISTSERV command syntax or use a complex dashboard. They should be able to review a plain-text email and reply with one word.
